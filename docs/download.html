⚠️ 初回起動時のセキュリティ警告について

macOS: 「開発元を確認できないため開けません」と表示される場合は、 「システム設定」→「プライバシーとセキュリティ」から「このまま開く」を選択してください。

インストール手順

1

ダウンロード

上記からお使いのOSに対応したファイルをダウンロードします。

2

インストール

macOS: DMGファイルを開き、アプリをアプリケーションフォルダにドラッグ&ドロップ。
Windows: EXEファイルを実行し、インストールウィザードに従ってインストール。
Linux: AppImageに実行権限を付与（chmod +x）して実行。または DEBをインストール。

3

初回設定

アプリを起動し、Googleアカウントでログイン。次にAI設定でお好みのAIプロバイダーとAPIキーを設定します。

4

プロジェクト作成

最初のプロジェクトを作成し、投稿プランを設定すれば準備完了です！

システム要件

macOS

  • macOS 10.15 (Catalina) 以降
  • 4GB RAM以上推奨
  • 500MB 空きストレージ

Windows

  • Windows 10 (64-bit) 以降
  • 4GB RAM以上推奨
  • 500MB 空きストレージ

Linux

  • Ubuntu 20.04 以降
  • 4GB RAM以上推奨
  • 500MB 空きストレージ
