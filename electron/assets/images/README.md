# アドプロ - 画像アセット

このディレクトリには、アプリで使用する画像ファイルを配置します。

## ロゴファイル

### 推奨ファイル名と形式

**ロゴファイル:**
- `logo.svg` - SVG形式（推奨）- スケーラブルで高品質
- `logo.png` - PNG形式（フォールバック用）- 透過背景
- `logo@2x.png` - Retina対応（2倍解像度）

**推奨サイズ:**
- SVG: ベクター形式なので任意のサイズに対応
- PNG: 最小 200x200px、推奨 400x400px以上
- Retina用: 800x800px以上

### ファイル配置方法

1. このディレクトリにロゴファイルをドラッグ&ドロップ
2. ファイル名を上記の推奨名にリネーム
3. Claude Codeに「ロゴを配置しました」と伝える

## 使用箇所

- ヘッダーロゴ（index.html）
- アプリアイコン（Electron）
- ファビコン（ブラウザタブ）
- スプラッシュスクリーン（起動時）

## カラーガイドライン

**ブランドカラー:**
- プライマリ: #4F46E5（インディゴ）
- セカンダリ: #06B6D4（シアン）
- アクセント: #F59E0B（オレンジ）

ロゴはこれらの色を使用するか、白・黒のモノクロバージョンも用意することを推奨します。
