# ad-project

## 構成

| ディレクトリ | 内容 |
|---|---|
| `electron/` | Electronデスクトップアプリ（こうこくーる管理ツール） |
| `instagram-mvp/` | Instagram投稿アシスタント（Next.js / Vercel） |
| `flutter_app/` | Flutterモバイルアプリ |

## instagram-mvp

```bash
cd instagram-mvp
npm install
cp .env.example .env.local  # GEMINI_API_KEY を設定
npm run dev
```

## electron

```bash
cd electron
npm install
npm start
```
